# ADR 0007. YARP как API Gateway

- **Статус:** Accepted
- **Дата:** 2026-04-10

## Контекст

Фронтенд не должен знать адреса всех микросервисов. Нужна единая точка входа с
маршрутизацией, проверкой JWT, CORS и rate-limiting.

## Решение

- **YARP** (Yet Another Reverse Proxy, Microsoft, open-source, на .NET).
- Gateway выполняет: маршрутизацию по путям (`/catalog`, `/basket`, `/order`…),
  проверку JWT, CORS для SPA, rate-limiting публичных форм, агрегацию health.
- На уровне k8s снаружи стоит **Nginx Ingress** (TLS через cert-manager), а YARP —
  внутренний API-шлюз приложения.

## Последствия

- (+) Единый вход, скрытие топологии, единая политика безопасности.
- (+) Вся экосистема на .NET, удобно конфигурировать и тестировать.
- (−) Ещё один сервис для мониторинга и деплоя.
- Альтернатива (отклонена): Ocelot — популярен, но YARP современнее и развивается
  Microsoft.
