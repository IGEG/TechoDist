# ADR 0006. Frontend: React + TS + Vite + Tailwind/shadcn

- **Статус:** Accepted
- **Дата:** 2026-04-10

## Контекст

Нужен современный дизайн, популярный стек, только бесплатные библиотеки.

## Решение

- **React + TypeScript + Vite** (быстрая сборка, современный стандарт).
- **Tailwind CSS + shadcn/ui** (Radix UI) — современный, кастомизируемый UI без
  runtime-зависимостей, легко добиться «своего» бренда.
- Состояние: **TanStack Query** (серверное) + **Zustand** (клиентское).
- Роутинг: **React Router**. Формы: **React Hook Form + Zod**.
- HTTP: **Axios** + генерация типов из OpenAPI (`openapi-typescript`).
- i18n: **react-i18next** (русский по умолчанию). Тесты: **Vitest + RTL + MSW**.

## Последствия

- (+) Современный вид, высокая скорость разработки, отличный DX.
- (+) Легко реализовать адаптивный дизайн и кастомную тему.
- (−) shadcn/ui — это «копируемые» компоненты в репозиторий, а не npm-пакет
  (это плюс для контроля, но нужно понимать модель).
- Альтернативы (MUI/AntD) отклонены: тяжелее и менее «штучный» вид.
